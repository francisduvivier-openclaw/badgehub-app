Non-agent proposal

N2 — Commit Workbench (Interactive)

Visual staging tool with commit lanes: rename, imports, refactor, logic. User drags hunks into lanes and commits in safe order.

UX highlights

  • Live dependency warnings
  • Per-lane validation hooks
  • Template workflows (rename-first, generated-last)

Pseudo implementation

loop:
  event = ui.next()
  if drag_hunk: assign()
  if validate: run_checks()
  if commit_lane: stage_lane(); commit()

Result example

Auto-bucketed: 80% obvious hunks
Manual review: 6 ambiguous hunks
Final output: 4 clean commits

Strength: precise and safe.
Weakness: slower than full automation.
