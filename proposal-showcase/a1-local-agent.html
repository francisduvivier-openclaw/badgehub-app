Agent proposal

A1 — SplitWise Agent (Local)

Problem: mixed commits combine mechanical and behavioral changes, making review expensive.

Core flow: plan → review → apply → verify.

splitwise plan --base origin/main
splitwise review
splitwise apply
splitwise verify

Example output

Before: 1 commit, 120 files changed
After:
1) chore(rename): move pkg/foo -> pkg/core/foo
2) chore(imports): rewrite @foo/* -> @core/foo/*
3) refactor(symbols): FooClient -> CoreClient
4) feat: add retry jitter

Pseudo implementation

hunks = parse(git_diff())
for h in hunks:
  cls, conf = classify(h)
  if conf < 0.85: queue_manual(h)
  else: assign(h, cls)
plan = order(assignments)
for c in plan: stage(c); commit(c.msg)

Guardrails: backup branch, dry-run, no force push without confirmation.
