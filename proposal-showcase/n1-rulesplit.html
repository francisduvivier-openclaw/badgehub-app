Non-agent proposal

N1 — Rulesplit CLI

Deterministic splitter using strict rules: R100 renames, import-only hunks, generated files, then remainder.

rulesplit analyze
rulesplit apply --rename --imports --generated

Pseudo steps

capture staged patch
bucket by rules
commit rename bucket
commit import bucket
commit generated bucket
commit remainder

Example

Input: 90 files mixed changes
Output:
- chore(rename): 50 files
- chore(imports): 28 files
- feat/fix: 12 files

Strength: reproducible and CI-friendly.
Weakness: no deep semantic intent inference.
