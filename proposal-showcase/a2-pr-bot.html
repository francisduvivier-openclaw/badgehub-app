A2 — PR Surgeon Bot (Server)

Problem: teams need consistent split quality and governance across repositories.

Flow: PR labeled needs-split → bot posts plan/risk → maintainer approves → bot rewrites branch with audit log.

Pseudo implementation

onPR():
  graph = load_commit_graph()
  plan = classify_and_split(graph)
  post_comment(plan, risk)

onApproveApply():
  create_backup_ref()
  rewritten = replay(plan)
  run_ci(rewritten)
  if pass: push_force_with_lease()

Example bot summary

Mechanical ratio in logic commits: 78% -> 31%
Low-confidence hunks requiring review: 2
Proposed rewritten commits: 7

Guardrails: protected branch policy, explicit approval, abort on conflicts by default.
