Commit Splitting Proposals

Goal: split large mixed commits into clean, reviewable commits for moves/renames/import churn versus behavioral logic changes. Built from first principles with human-in-the-loop safety.

Agent

A1 — SplitWise Agent (Local CLI/IDE)

Classifies hunks by intent with confidence scores and lets users approve before commit materialization.

Agent

A2 — PR Surgeon Bot (Server)

Team-wide PR automation: proposes split plans, applies rewrite after maintainer approval, and audits outcomes.

Non-Agent

N1 — Rulesplit CLI

Deterministic rule-based splitting using Git metadata and configured heuristics.

Non-Agent

N2 — Commit Workbench

Interactive GUI/TUI with commit lanes and drag-drop hunk control for precision splitting.
